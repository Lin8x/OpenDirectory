# Changelog

All notable changes to OpenDirectory. Generated by `cargo x release` from Conventional Commits.
## v0.7.0 (2026-11-25)

### Features

- **pki:** machine certificate auto-enrollment, printer and DFS guidance
- **dc:** Samba-backed domain controller role and domain join templates
- **ldap:** read-only LDAP and LDAPS server with AD-style schema
- **mdm:** mobile device inventory and Apple configuration profiles

### Documentation

- describe v0.7 features and remaining gaps

## v0.6.0 (2026-11-25)

### Features

- **admin-center:** Network Services screens for DNS, DHCP, CA and RADIUS
- **radius:** RADIUS server for VPNs and network devices
- **ca:** internal certificate authority and trusted-root GPO
- **dhcp:** DHCPv4 server with scopes and reservations
- **dns:** authoritative DNS server for the domain

### Other changes

- satisfy clippy

## v0.5.0 (2026-11-25)

### Features

- remote desktop and SSH through secure tunnels
- interactive remote shell and instant agent wake-ups
- **patching:** patch management for every OS
- LAPS, Recycle Bin and password policy screens
- **directory:** Recycle Bin and fine-grained password policies

### Fixes

- **agent:** allow the macOS update parser on other OSes

### Documentation

- describe the v0.5 features

## v0.4.0 (2026-11-25)

### Features

- web mode and Docker image with compose and Portainer
- Network Lab simulator and live Topology Map
- **admin-center:** classic console interface
- **integrations:** Windows Services and Cloud & Alerts
- **branding:** company logo, accent color and product name
- **backup:** encrypted one-file backups with schedules

## v0.3.0 (2026-11-25)

### Features

- onboarding baselines, launch at startup and od init
- **policy:** 18 new cross-platform GPO settings
- Script Library with templates, group/OU targeting and GPO scripts
- **admin-center:** show clearly whether the Admin Center is up to date
- **xtask:** add scripts/ wrappers for every task and a beginner guide

### Fixes

- **xtask:** find rustup's cargo under sudo and run scripts as the invoking user
